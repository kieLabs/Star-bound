# STARBOUND PUZZLE — GamerKie Edition
**One hero. Infinite worlds. A different puzzle every time.**

An original 2D side-view physics-puzzle adventure inspired by the uploaded video's minimalist silhouette/physics mood. It does not copy its characters, artwork, levels, or branding.

## Features
- Procedural endless sectors: each sector is generated from its number and rotates through six puzzle families.
- ORB: push an energy core onto a floor plate.
- SHARDS: collect all energy shards before exiting.
- SWITCH: find and activate a control node.
- SWING: attach/release a tether at anchor points to cross a gap.
- DODGE: time your movement around pulsing energy gates.
- TWIN: move two cores onto two floor nodes.
- Keyboard and touch controls; progress and shard count saved locally.
- Canvas graphics are drawn in code; no external assets, frameworks, servers, or API keys.

## Run locally
Open `index.html` in a modern browser. For best results, use a local static server.

## GitHub Pages
1. Create a public repository, e.g. `Starbound-Puzzle`.
2. Extract this ZIP and upload the **contents** (index.html, css, js, README.md, assets folder) to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Wait for deployment. Your game URL will be `https://YOUR-USERNAME.github.io/Starbound-Puzzle/`.

## Blogger embed
Create a Blogger post in HTML view and paste the iframe snippet from `blogger-embed.html`. Replace `YOUR-USERNAME` and repository name with your actual GitHub Pages address. Set the post to full width if your theme supports it.

## Controls
Desktop: A/D or ←/→ to move, Space/W/↑ to jump, E to interact/tether.
Mobile: on-screen ◀ ▶, USE and JUMP buttons.

## Note
The level generator creates a deterministic, new arrangement and puzzle family for each sector. This is an endless procedural arcade-puzzle prototype, not a hand-authored campaign; physics and challenge variety can be expanded in future updates.
